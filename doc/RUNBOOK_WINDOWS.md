# Paperclip на Windows: одна задача, простые шаги

Оформлено по стандарту `standards/works/work-task-writing` (input → output → чеклист).

## Problem Statement

Нужно стабильно запускать Paperclip локально на Windows без ручной «чистки» по всему репозиторию и без ошибок доступа к файлам.

## Input

- Папка репозитория: `paperclip`
- Установлены Node 20+ и pnpm 9+
- Терминал **не** «Запуск от имени администратора»

## Output

- Описаны только три команды на каждый случай
- Добавлена безопасная очистка артефактов: `pnpm clean:workspace-dist` (не трогает `node_modules`)

## Outcome

Можно повторять цикл «очистка → сборка → дев» без поломки зависимостей и без лишних объяснений.

---

## Чеклист: первый запуск / после `git pull`

| Пункт | Сделано |
|-------|---------|
| Выполнена команда `pnpm install` в корне `paperclip` | ☐ |
| Выполнена команда `pnpm build` без ошибок | ☐ |
| Выполнена команда `pnpm dev` в обычном терминале | ☐ |
| В браузере открыт `http://localhost:3100` и открывается интерфейс | ☐ |

---

## Чеклист: «хочу пересобрать с нуля» (только свой код, не ломая npm)

| Пункт | Сделано |
|-------|---------|
| Остановлен дев: `pnpm dev:stop` (если запускали `pnpm dev`) | ☐ |
| Выполнено: `pnpm clean:workspace-dist` | ☐ |
| Выполнено: `pnpm build` | ☐ |

**Не делать:** искать и удалять все папки с именем `dist` по всему репо — так удаляется `dist` внутри `node_modules` и установка ломается.

---

## Чеклист: если Windows пишет «Отказано в доступе»

| Пункт | Сделано |
|-------|---------|
| Закрыты лишние терминалы и остановлен `pnpm dev` | ☐ |
| Повторены `pnpm clean:workspace-dist` и `pnpm build` | ☐ |

---

## Три команды на память

1. `pnpm install` — зависимости  
2. `pnpm build` — собрать всё  
3. `pnpm dev` — поднять локально, UI: **http://localhost:3100**
